# Uber Eats Bangalore - Restaurant Intelligence & Decision Support System

## Project Overview
End-to-end data analysis and decision support system for Uber Eats Bangalore restaurants using Python, MySQL, and Streamlit.

### Key Features
- Data Cleaning & Feature Engineering (Pandas)
- MySQL Database Integration
- 10+ Business Questions answered with SQL
- Interactive Streamlit Dashboard (Tabular only)
- Order dataset analysis

### Tech Stack
- **Python** + Pandas + NumPy
- **MySQL** (Cursor-based queries)
- **Streamlit** (Pure tabular outputs)
- Jupyter Notebooks for EDA

### How to Run Locally
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Update MySQL credentials in notebooks
4. Run `streamlit run app.py`

### Business Questions Answered
- Top rated locations
- Over-saturated areas
- Impact of online ordering & table booking
- Best price segments
- Revenue analysis using orders data
- And many more...
